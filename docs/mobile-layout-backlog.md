# 모바일 전용 레이아웃 후속 작업

현재 단계에서는 브라우저·태블릿 크기에 맞는 반응형 작업 영역과 QR 스캔 모바일 안전 화면까지만 적용한다.

앱 전체 기능이 안정화된 뒤 아래 항목을 별도 모바일 화면으로 재설계한다.

- 하단 탭 중심의 모바일 전용 메뉴
- QR 스캔을 첫 화면으로 두는 입장 직원 동선
- 좌석 현황은 전체 SVG 축소본 대신 검색·상태·최근 처리 중심으로 단순화
- 오류·중복·미배정 확인은 전체 화면 모달로 통일
- 최소 44px 터치 영역, 한 손 조작, 느린 네트워크·오프라인 안내 검증
- 실제 iPhone·Android 기기 및 Safari·Chrome에서 카메라 연속 스캔 검증

모바일 재설계 전까지는 앱 전체 브라우저 확대를 제어하지 않으며, 좌석표 확대는 좌석표 박스 안에서만 제공한다.
