# 홀 좌석 현장 운영 시스템 구조

## 현재 단계

- Next.js App Router와 TypeScript 기반의 정식 애플리케이션 뼈대
- 검증된 태블릿 운영 미리보기와 목업 데이터
- Supabase 브라우저·서버 클라이언트 준비
- 실제 인증, 데이터베이스 스키마, Realtime 연결은 다음 단계에서 적용

## 운영 범위

모든 화면은 `홀 → 행사 → 회차` 선택을 기준으로 동작합니다. 서로 다른 홀의 운영 수치는 합산하지 않습니다.

## 보안 기준

- 브라우저에는 프로젝트 URL과 Publishable key만 사용합니다.
- DB 비밀번호, Secret key, Service Role key는 저장소에 커밋하지 않습니다.
- 공개 스키마의 테이블에는 RLS와 업무 범위별 정책을 적용합니다.
- 좌석 배부·입장·취소·재배정은 클라이언트 상태가 아니라 DB 트랜잭션으로 확정합니다.
